# LoiLoNote 統整卡（選用收尾步驟）

Celine 2026-10-14 決定：PDF、16:9 橫式；LoiLoNote 匯入 PDF 時每頁＝一張卡。

## 何時做
- 講義交付後問一句「要不要順便做 LoiLo 統整卡？」；也可單獨叫用（「幫 U2 Reading 做 LoiLo 卡片」）。
- 每單元每個 Part（Dialogue / Reading）一套，**S1–S4 共用**（統整內容四軌一致）。

## 內容來源
- 教師版各 Task 的「📋 統整」＋ Unit Brief 的 Answer Bank。只做統整，不放新內容。
- 卡片不可出現只屬於某一軌的選項代號（例：Part B 各軌答案字母不同 → 卡片寫選項文字，不寫 B/C）。
- 一張卡只講一件事；建議 8–11 張：封面、策略步驟、策略圖答案、Keep/Cut 或證據、摘要／時間線、Reading Clue、課文證據、Part B 解題法、T3 成品框架＋Idea Bank、S4 重音／發音（標 S4）。
- **D／R 統整卡不放文法卡**（2026-11-02，講義已不放文法題）；文法改做下面的「文法卡」。

## 來源檔與輸出
- 來源：`<輸出資料夾>/src/<filename>_LoiLo卡片.md`（語法見 `scripts/render_cards.py` 開頭；同講義的 `[[ ]]`、`{{a* / b}}`、`[[x]]`）。
- 輸出：`<輸出資料夾>/LoiLo卡片/`
  - `_成對版.pdf`：挖空頁 → 答案頁連續（上課投影用；沒有空格的卡只出現一次）
  - `_挖空版.pdf`：只有挖空頁（可發給學生）
  - `_答案版.pdf`：只有答案頁
```bash
python3 ~/.claude/skills/four-track-handout/scripts/render_cards.py SRC_LoiLo卡片.md --out-dir OUT/LoiLo卡片
```
  - `_漸進版.pdf`（2026-10-17 起，上課投影的主檔）：挖空頁 → 每翻一頁多揭曉一列（表格列／條列／單行），最新揭曉的答案黃底、先前的紅字；右上角「揭曉 n/N」。沒有空格的卡只出現一次。
  - 揭曉順序預設由上而下、一列一步；超過 6 步自動合併。要調順序：`[[答案@2]]`（放進第 2 步，同步一起出現）、`[[答案@last]]`（最後一步才揭曉，例如結論框、❌→✅ 改錯框、T1 投票卡的答案框）；整張一次揭曉：卡片開頭加 `reveal: all`。
- 挖空頁用「同一段文字但透明」排版，所以挖空頁與答案頁位置完全相同，翻頁＝揭曉。

## QA
- 轉 PNG 看：挖空頁沒有任何答案外漏（圈選題要把所有選項放在同一個 `{{ }}` 裡，單一選項的 `{{x*}}` 會在挖空頁露出括號＝外漏）；內容沒有超出頁面；字夠大（內文 34px）。

## 卡片內容要和講義逐字一致（2026-10-29）
- 卡片上的表格／題目若來自講義，句子、題號、順序都要和該軌講義（通常 S1/S2）一模一樣，不可自行刪減或改寫；S3 只用其中幾句時，在教師版說明即可。
- 列數多（約 8 列以上）放不下時，在該卡加 `compact: true`（字級與列距縮小），不要刪內容。

## 文法卡（獨立一套，2026-11-02）

文法另外上專門的文法課（教材是學生講義合訂本的「文法解析」頁）；講解時投影 LoiLo 視覺卡很有幫助。

- **何時做**：老師說「做 U# 文法卡」時才做；產生四軌講義時不自動做。
- **一單元一套**：`<單元資料夾>/文法/src/115-1_G8_B3_U#_文法_LoiLo卡片.md` → `<單元資料夾>/文法/LoiLo卡片/`（同一支 `render_cards.py`）。
- **順序跟著 Handouts「文法解析」的段落**（壹、貳一、貳二…），每張卡的 `tag:` 寫段落和頁碼（例：`貳-一 to V｜p. 60`），老師翻到哪頁，卡片就在哪一段。
- 頁碼與講義 PDF 位置：查 `teacher-profile.md`「文法解析頁碼」；沒有填就先問老師，再幫他填好。
- **每一段 2–3 張**：① 句型圖（顏色表格／公式，一眼看懂）② 從課文找例子（用本課 Dialogue／Reading 的原句，先挖空再揭曉）③ 常見錯誤（❌ → ✅，揭曉放 `@last`）。
- **例句以課文原句優先**（學生讀過的人物，像 Yuki、IU），不足時才自編；Handouts 已有的例句與練習題不重抄（學生手上有紙本）。
- 第一張封面列出本套涵蓋的段落與頁碼。
