# 四軌講義核心理念（Celine Lee）

來源：Celine Lee 的 B2 U1–U6 S1–S4 講義、四軌生成指令、利真老師 B1–B3 S1 統整，以及 115 B3 U1–U2 上課定稿。感謝利真老師的四軌講義，詳見 Shareclass 網站：https://www.shareclass.org/profile/dacbeb5aceaa4f889d2faf4510c4a544/

## 1. 一句話原則

**同一個單元、同一個中心思想、同一組文本證據；不同的鷹架與輸出量。**
四軌的「Task 功能、核心提問、正確答案的事實」必須一致，讓全班在討論與統整時有共同語言。改變的只有：提示多寡、作答形式（寫句／填關鍵字／圈選）、Word Bank、中文註解、時間長度、輸出份量。

## 2. 四軌學生輪廓

| 軌 | 程度 | 需要什麼 | 講義感覺 |
|---|---|---|---|
| S1 自主深化 | 月考 90+，1200–2000 字 | 開放、推理、全英文、無 Word Bank、文法說明「為什麼」 | 智力挑戰；留白多、提示少 |
| S2 結構引導 | 80–90，國七程度、1200 字不熟 | 與 S1 同題，但用 organizer／引導問題／括號中文註解拆步驟 | 有地圖、不迷路 |
| S3 基礎鷹架 | 60–80，年段單字不熟 | 同一題目改成圈選、勾選、5–6 字 Word Bank 克漏、句框；保留思考 | 「我做得到」的成就感 |
| S4 基礎重建 | 60 以下，國小程度，拼讀困難 | 單字重建（拍音節、切音、KK、紅綠燈、救援站）＋原文 3 核心句 | 親切、圖示、小步驟、中英混合 |

稱呼一律用 S1–S4 或 Level，不用「優等／補救」。

## 3. 學思達流程與圖示

`👤🧠 自學思考 → 👥 討論 → 📢 表達 → 📋 統整`

- `👤`：純個人操作（跟讀、抄寫、第一次聽）。`👤🧠`：個人思考、推論、自評。
- 每個 Task 只放實際發生的階段。流程列一定要有 emoji，不可只剩箭頭。
- Task 1 自學（觀察、預測、策略）→ Task 2 思考（文本證據、聽力、文法推理）→ Task 3 表達（4/3/2 流暢度或主題寫作）→ Task 4 口說評量（QR 錄音）→ Task 5 統整（QR 解說影片＋手寫筆記上傳）。

## 4. 提問設計

- **Bloom 梯度**：同一題的核心事實相同，S4/S3 偏記憶、理解；S2 加分析；S1 加評鑑、創造。
- **Local → Global**：先找細節，再讀出言外之意或連結自己／社會。
- **以文本為證**：要求回課本找證據（Page __, Line __ 或「Write words from the text」）。
- 思考常規（See-Think-Wonder、I used to think…、Circle of Viewpoints、Claim-Support-Question…）必須真的問「觀察／推論／觀點轉換」，不能只是標題下放課本事實題。

## 5. Instruction 標準（最重要的品質點）

**Instruction 是講義最重要的部分。** 學生要能不靠老師口頭補充，只讀 Instruction 就知道怎麼做。

### 5.1 用學思達五環寫步驟

每段 Instruction 依照該 Task 實際發生的環節，用編號短步驟寫出，並在步驟前標環節圖示：

1. `👤` 自學：看哪裡／聽什麼、聽幾次。
2. `🧠` 思考：做什麼判斷（圈、選、找證據、寫原因），寫幾個、用什麼格式。
3. `👥` 討論：和誰、核對或練習什麼。
4. `📢` 表達：說給誰聽、說什麼、說多久。
5. `📋` 統整：聽老師統整什麼（具體：時間表、was/were 規則…）。

只寫實際發生的環節。flow 列與 Instruction 步驟必須一致。

### 5.1a 步驟緊接題目（Celine 2026-10-14 決定，U4 起適用）

- **不要**在 Task 開頭一次列出全部步驟。每一步放在它要做的那一題「正上方」，學生讀完一步就看到要做的題目。
- 指到某一題的步驟要寫出是哪一題：Fill in **the timeline in A**、Answer **Questions 1-8**、Circle the right words **in B**。
- 編號在一個 Task 內接續（Step 1、2、3…；S4 為「第 1 步」），順序仍照五環。
- 👥 討論、📢 表達、📋 統整這類「做完全部題目才做」的步驟，放在該 Task 最後一題下面（或簽名列上方）。
- 不顯示「Instruction:」灰色標籤；Task 4、Task 5 也用同樣的 Step 行。
- 來源檔語法：`step: 👤 Listen to …`（見 source-format.md）。

### 5.2 CEFR A1 語言（四軌都適用，S1 也一樣）

- 一句只做一件事；每句 ≤ 12 字；用祈使句：Look / Listen / Read / Write / Circle / Check / Talk / Tell / Share。
- 只用 A1 高頻字。避免：compare evidence、infer、synthesize、organizer、extension、response 等字；改成 look again、find the words、check with your partner、say more。
- 數量寫清楚：Write **3** sentences. Listen **2** times. Talk for **35 seconds**.
- 例：
  ```
  👤 Listen to the Dialogue 2 times. (CD2: 1-4)
  🧠 Write what each person was doing. Use full sentences.
  👥 Check your answers with a partner.
  📋 Listen to your teacher. Check the time line.
  ```
- 語言比例：S1 全英文；S2 英文＋關鍵字括號中文；S3 英文短句＋中文翻譯（每步一行中英）；S4 中文為主、英文關鍵字。

### 5.3 文本輸入一律用音檔

聽力與跟讀一律用課本音檔（CD 軌號）或 QR 音檔、對話動畫。**絕不寫「老師朗讀課文給學生聽」**，教師版也不可以這樣建議。

- 表格每一列要有具體問題或動作，不能只寫 `Prompt`、`People / action / object` 這種簡寫。

## 6. 流暢度（4/3/2）原則

- Speaking Map **只寫關鍵字，禁止寫完整句**（寫完整句就變朗讀比賽）。S3 可用句框，S4 用三句短句。
- 流暢度素材必須是學生 100% 已學過的語言（Paul Nation），不在這裡加新字或新文法。
- 三輪換三位夥伴、時間遞減、說同一內容；夥伴簽名＋★回饋。

## 7. S4 單字重建理念

資訊降解＋極大化語音鷹架，避免習得性無助：
- **單字建築師**：切音節小秘訣（找母音、子音靠近母音、雙子音拆開、雙母音不拆）＋範例字（找母音 → 切音節 → KK → 中文 → 圖像）。學生自己填 Claps 與 Sound chunks；KK 與中文是校正支援。
- **KK 音標助念員**：挑本課常見母音（/aɪ/ 愛、/e/ ㄟ、/æ/ 蝴蝶音…）配本課例字。
- **單字紅綠燈**：全字表自評 🟢 / 🟡 / 🔴（會唸、會拼、知道意思）。
- **單字救援站**：選 3–4 個紅黃燈字，用 A 生活例句魔法 ✨、B 小畫家記憶法 🎨、C 錯點螢光筆 🔦、D 諧音小幫手 🔊；一定附老師示範例。
- **單字乒乓賽**：Level 1 指字說英文、Level 2 聽中文說英文，夥伴簽名；小挑戰收尾（我成功把 ___ 從紅燈變綠燈）。

## 8. 明確反對的設計

1. 各軌 Task 功能不同（S3 做完全不同的題型、S1 寫偶像 S3 勾選觀念）。
2. 各單元共用樣板內容（同樣的四個選擇題、同樣的教師說明套在每個 Task）。
3. 解答版只寫「四區都完成」這種泛用摘要。
4. Reading 的「My first topic… My final topic」／先答再保留或修改（AI See Learn 線上任務作法）。
5. 把 Task 4 錄音與 Task 5 影片筆記合併，或改成純紙本。
6. S1 給中文翻譯整句或 Word Bank。
7. 4/3/2 寫整句講稿；流暢度活動加入新語言。
8. 給 S4 整篇長文本又不給解碼支援；或剝奪 S4 的思考（S4 也要有「選擇、判斷、救援」）。
9. 跨軌文字外漏（S1 講義出現「S3: 25 seconds」）。
