# 教用版（紅字解答）與教師版

每一軌只寫一份來源檔；渲染器同時產生：
- `…_S1.docx`：學生版，`[[答案]]` 顯示為底線空格。
- `…_S1_教用.docx`：**同一份講義，答案以紅色粗體寫在空格上**，最後接教師版。

## 紅字答案規則

- 依「該軌講義本身」作答：S3 的圈選題就標出圈選的字，S1 的開放句就寫一個完整範例句。
- 每一個固定答案都要用 `[[ ]]` 標在正確位置（填空、表格欄、選擇題代號、勾選框、配對順序）。不可只在最後寫一段總結。
- 開放題用 `lines: N | 參考答案 | 可接受條件`：學生版顯示 N 條寫線，教用版顯示紅字範例與評分條件。
- 勾選題：正確項寫 `[[x]] A`，其他寫 `□ B`（學生版都顯示 □，教用版正確項為紅色 ☑）。
- 圈選題：`{{was* / were}}`，星號標正確項（教用版紅字）。
- 選擇題代號：`My answer: [[B|6]]`。
- 只給老師看的補充：`key: …`（只出現在教用版）。
- S4 單字表：示範列直接填好；其餘列的 Claps、Sound chunks 用 `[[2]]`、`[[kitch / en]]`。

## Bloom 標籤（2026-11-02，Celine：「教師版要標 Bloom 層次」）

- 每一題（或一個題組／表格）的 `### ■` 小標下一行寫 `bloom: 推論`、`bloom: 1 理解｜2 推論｜3 評鑑｜4 評鑑＋遷移`。教用版顯示灰色小字「🎯 Bloom：…」，學生版不出現。
- 用語：記憶、理解、應用、分析、評鑑、創造；可加括號說明（推論、遷移、連結自己）。S4 也要標（多半是記憶／應用；救援站、紅綠燈是評鑑自己的學習）。
- Task 4、Task 5 也要標（T4 應用／創造；T5 理解＋評鑑：I used to think … Now I think …）。

## 教師版（`=== TEACHER GUIDE ===` 之後）

每個 Task 都要寫**本軌、本課特有**的內容，不可五個 Task 共用一段：
1. **教學目的**（一句，連到本課內容）。
2. **時間**。
3. **操作步驟**：老師說什麼、何時巡堂、何時兩兩核對。
4. **📋 統整腳本**（每個 📋 停點各一段）：
   - 整理學生答案（巡堂看到的 2–3 種答案）→ 點出好的證據 → 連回核心問題。
   - 老師示範句（一句）。
   - 只有 T1 See-Think-Wonder「老師示範自己的範例」標 **（帶幾次後拿掉）**；其他統整照常做，不標。
   - 小組牆的統整寫「下一堂開場」；Task 5 寫「下一堂開場用上傳筆記講評 3–5 分鐘」。
5. **常見錯誤與回應**：本課學生最可能錯的 1–2 點（例：把 was doing 寫成 was do）。
6. `Bloom：…｜會考能力：…` 總覽一行（T1–T5 都要，S4 也要）。
