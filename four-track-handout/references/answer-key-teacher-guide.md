# 教用版（紅字解答）與教師版

每一軌只寫一份來源檔；渲染器同時產生：
- `…_S1.docx`：學生版，`[[答案]]` 顯示為底線空格。
- `…_S1_教用.docx`：**同一份講義，答案以紅色粗體寫在空格上**，最後接教師版。

## 紅字答案規則

- 依「該軌講義本身」作答：S3 的圈選題就標出圈選的字，S1 的開放句就寫一個完整範例句。
- 每一個固定答案都要用 `[[ ]]` 標在正確位置（填空、表格欄、選擇題代號、勾選框、配對順序）。不可只在最後寫一段總結。
- 開放題用 `lines: N | 參考答案 | 可接受條件`：學生版顯示 N 條寫線，教用版顯示紅字範例與評分條件。
- 勾選題：正確項寫 `[[x]] A`，其他寫 `□ B`（學生版都顯示 □，教用版正確項為紅色 ☑）。
- 圈選題：`{{was* / were}}`，星號標正確項（教用版紅字）。
- 選擇題代號：`My answer: [[B|6]]`。
- 只給老師看的補充：`key: …`（只出現在教用版）。
- S4 單字表：示範列直接填好；其餘列的 Claps、Sound chunks 用 `[[2]]`、`[[kitch / en]]`。

## 教師版（`=== TEACHER GUIDE ===` 之後）

每個 Task 都要寫**本軌、本課特有**的內容，不可五個 Task 共用一段：
1. **教學目的**（一句，連到本課內容）。
2. **時間**。
3. **操作步驟**：老師說什麼、何時巡堂、何時兩兩核對。
4. **📋 統整重點**：老師最後要收束的具體答案、規則或板書（例：was/were 的主詞配對表）。
5. **常見錯誤與回應**：本課學生最可能錯的 1–2 點（例：把 was doing 寫成 was do）。

最後一節「課前檢核」：QR 是否已貼、頁碼、音檔、與其他三軌的核心題是否一致。
