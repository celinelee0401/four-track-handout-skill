=== TEACHER GUIDE ===
適用：S2（與 S1 同題同事實；改為 organizer、括號中文、句框）。課本 pp. 49–50，CD2: 1–4。

## Task 1: See-Think-Wonder（10 分鐘）
- 目的：看圖預測「誰打破杯子」，讓聽力有目的。
- 步驟：蓋住文字看圖 3 分鐘 → 兩兩找不同想法 → 每組分享一個 Think。
- 📋 統整：黑板列出嫌疑人（Lucky / Mom / Jamie / Kim），先不公布答案。
- 常見錯誤：See 寫成猜測；提醒 See 只寫看得到的。

## Task 2: Dialogue Listening（15 分鐘）
- 目的：完成時間線與偵探表，操作 was/were + V-ing、when。
- 步驟：播 CD2: 1–4 兩次（闔書）→ 開書找原句 → 兩兩核對。
- 📋 統整：黑板時間線 12:30 Mom / 1:15 Jamie / 2:00 Kim；「長動作 was V-ing ＋ when ＋ 短動作 過去式」圖示。
- 常見錯誤：was drink（漏 -ing）；C2 把 broke 當長動作——用「夢遊一整段時間，杯子一下就破」說明。

## Task 3: Take It Easy & 4-3-2（15 分鐘）
- 目的：SEL 先冷靜再查證；用過去進行式流暢說昨晚的事。
- 步驟：Part A 句框作答 3 分鐘 → 兩兩分享；Part B Speaking Map 只寫關鍵字 → 三輪 35/30/25 秒。
- 📋 統整：請 2 位學生說 I was … when … 句，全班複述。
- 常見錯誤：Speaking Map 寫整句；三輪換不同夥伴時改說不同內容（應說同一內容、越說越順）。

## Task 4: Speaking Evaluation（課後）
- 評分重點：完整對話、兩種聲音、was/were + V-ing 正確、30 秒延伸。

## Task 5: Dialogue Explanation（課後）
- 目的：影片複習 half past / a quarter after 與過去進行式；下一堂依筆記抽查。
