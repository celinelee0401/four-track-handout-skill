適用：S3（與 S1/S2 同目的、同事實；作答改為圈選、勾選、Word Bank、句框，指令中英對照）。課本 pp. 49–50，CD2: 1–4。

## Task 1: See-Think-Wonder（8 分鐘）
- 目的：用圖片關鍵字建立情境（杯子、監視器、洗碗、閉眼），並預測兇手。
- 步驟：圈選 → 填句 → 對組員說一句；Think 全班舉手投票誰是兇手。
- 📋 統整：黑板寫 cup / dog monitor / doing the dishes / closed，並帶唸。
- 常見錯誤：只圈不填；提醒「圈 → 寫 → 說」三步都要做。

## Task 2: Dialogue Listening（15 分鐘）
- 目的：聽懂三個時間點的事實，並分辨 was / were、V-ing。
- 步驟：第一次聽（闔書）完成 A 勾選；第二次聽完成 B；開書核對。
- 📋 統整：時間線 12:30 Mom / 1:15 Jamie / 2:00 Kim；was 配 I/he/she/Mom，were 配 you/we/they。
- 常見錯誤：B5 寫 close（與 B4 混淆）；C3 選 sleepwalk（漏 -ing）。

## Task 3: Take It Easy & 4-3-2（15 分鐘）
- 目的：SEL 先冷靜再查證；用三句句框說昨晚的事。
- 步驟：Part A 勾選＋句框；Part B 先和夥伴練三句，再三輪 25/20/15 秒。
- 📋 統整：全班一起說 Take it easy. Let's check the facts.
- 常見錯誤：At 7 p.m., I was eat dinner（漏 -ing）——說之前先檢查句框。

## Task 4: Speaking Evaluation（課後）
- 評分重點：完整對話、聲音清楚、句框 2–3 句含 was + V-ing。

## Task 5: Dialogue Explanation（課後）
- 目的：影片複習時間說法與 was/were + V-ing；下一堂依筆記抽查。
