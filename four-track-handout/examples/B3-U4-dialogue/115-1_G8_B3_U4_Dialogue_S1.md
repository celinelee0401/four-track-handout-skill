=== TEACHER GUIDE ===
適用：S1（全英文、無 Word Bank、要求推理與文法說明）。課本 pp. 69–70，CD2: 20–23。

## Task 1: See-Think-Wonder（10 分鐘）
- 目的：從插圖預測三人的夢想職業，並推論 Yuki 遮臉的原因（緊張），讓 Task 2 聽力有目的。
- 步驟：學生先蓋住文字只看圖 3 分鐘 → 兩兩找一個不同想法 → 每組分享一個 Think。
- 📋 統整：黑板寫三人的「猜測職業」（影片／律師／歌手）與 Think 的感受字（nervous / shy），先不公布答案。
- 常見錯誤：See 寫成猜測（She is nervous.）。提醒 See 只寫看得到的事（She covers her face with a fan.）。

## Task 2: Dialogue Listening（15 分鐘）
- 目的：聽懂三人的夢想與理由、Yuki 的困擾與朋友的建議，並操作本課文法 to V / V-ing。
- 步驟：播 CD2: 20–23 兩次（闔書）→ 開書找原句 → 兩兩核對 → 全班完成夢想職業表；C 小組討論後發表。
- 📋 統整：黑板夢想職業表（Zac–YouTuber–enjoys making videos／Cody–lawyer–help people in need／Yuki–singer–good at singing），再畫兩欄「to V：want / hope / plan / need」「V-ing：enjoy / keep / practice / finish」，like / love / hate 兩邊都可；Being a singer＝V-ing 當主詞。
- 常見錯誤：enjoy to make、hope being；Being 寫成 Be a singer is…；把 butterflies 當真的蝴蝶。

## Task 3: Butterflies? Keep Practicing! & 4-3-2（15 分鐘）
- 目的：SEL——承認緊張是正常的，用練習與朋友支持面對；用本課句型流暢說自己的夢想職業。
- 步驟：Part A 個人寫 3 分鐘 → 兩兩分享；Part B Speaking Map 只寫關鍵字 2 分鐘 → 三輪 35/30/25 秒，換三位夥伴。
- 📋 統整：收集全班給 Yuki 的新點子；請 2 位學生說 I want to be … because … / I enjoy V-ing …，全班複述。
- 常見錯誤：在 Speaking Map 寫整句；I want to be a sing（職業名詞要用 singer）；I enjoy to draw。

## Task 4: Speaking Evaluation（課後）
- 目的：完整朗讀對話（三種角色聲音）＋ 30 秒說自己的夢想職業。
- 評分重點：清楚度、三種聲音、正確使用 to V / V-ing、30 秒完整。

## Task 5: Dialogue Explanation（課後）
- 目的：影片複習 to V / V-ing 動詞分類、Being 當主詞、get butterflies 的意思；學生手寫筆記上傳。
- 下一堂：依筆記抽查 enjoy / hope / keep 後面接什麼。
