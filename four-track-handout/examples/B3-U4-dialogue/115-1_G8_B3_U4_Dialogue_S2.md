=== TEACHER GUIDE ===
適用：S2（與 S1 同題同事實；加例字、括號中文、表格與句框、文法二選一＋說明）。課本 pp. 69–70，CD2: 20–23。

## Task 1: See-Think-Wonder（10 分鐘）
- 目的：從插圖預測三人的夢想職業，並推論 Yuki 遮臉的原因。
- 步驟：只看圖 3 分鐘 → 兩兩找一個不同想法 → 每組分享一個 Think。
- 📋 統整：黑板寫三人的猜測職業與 nervous / shy，先不公布答案。
- 常見錯誤：See 寫成感受；提醒 See 寫看得到的（fan、wig、phone）。

## Task 2: Dialogue Listening（15 分鐘）
- 目的：同 S1——三人的夢想與理由、Yuki 的困擾與建議、to V / V-ing。
- 步驟：播 CD2: 20–23 兩次（闔書）→ 開書核對 → 兩兩核對 → C 文法分類。
- 📋 統整：夢想職業表；兩欄「to V：want / hope / plan / need」「V-ing：enjoy / keep / practice / finish」；Being a singer＝V-ing 當主詞。
- 常見錯誤：A 欄寫 singing（職業要寫 singer）；C2 圈 to make。

## Task 3: Butterflies? Keep Practicing! & 4-3-2（15 分鐘）
- 目的：SEL——面對緊張；用本課句型說自己的夢想職業。
- 步驟：Part A 句框 3 分鐘 → 兩兩分享；Part B 引導問題寫關鍵字 2 分鐘（可參考 Speaking Help）→ 三輪 35/30/25 秒。
- 📋 統整：全班給 Yuki 的新點子清單；示範 I want to be … because … / I need to practice V-ing。
- 常見錯誤：Speaking Map 抄整句 Speaking Help；I need to practice draw（practice 後接 V-ing）。

## Task 4: Speaking Evaluation（課後）
- 評分重點：三種聲音、清楚度、to V / V-ing 正確、30 秒完整。

## Task 5: Dialogue Explanation（課後）
- 目的：影片複習 to V / V-ing 分類與 Being 當主詞；筆記寫在 Handout pp. 70–71 並上傳。
